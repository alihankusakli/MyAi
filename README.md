# MyAI — Personal Digital Twin

An AI system that replicates my thinking patterns, communication style, and personal knowledge base.

## How it works
- Personal data (notes, writings, experiences) is stored in ChromaDB as vectors
- When you ask a question, the RAG system finds the most relevant pieces of my data
- The answer is generated by the best LLM for that question type

## Tech stack
- Python
- ChromaDB (vector database)
- RAG (Retrieval-Augmented Generation)
- Anthropic Claude, OpenAI GPT-4o mini, Google Gemini
- Streamlit (web interface)

## Run locally
```bash
pip install -r requirements.txt
python ingest.py
streamlit run app.py
```
